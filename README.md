# Fauzan Abdurrahim

First-principles calculations of heavy-metal/ferromagnet interfaces for spin-orbit torque memory (SOT-MRAM).

- Spintronics Laboratory, Mie University, Japan
- Department of Physics, Universitas Gadjah Mada (UGM), Indonesia

**Now:** atomic structure of ultrathin Fe films on W(001) with GOFEE (AGOX + GPAW); next, the spin Hall conductivity of that interface.

Email: fauzanabdurrahim@mail.ugm.ac.id

### Research interests
- Spintronics, spin-orbit torque, interface magnetism
- Density functional theory, machine-learning-assisted structure search
- Plasmonic nanomaterials (previous work)

### Publication

### Tools
Python, ASE, GPAW, AGOX, VESTA, Linux, Bash, Git, HPC clusters
